# My Helston

## Summary

Community information platform for Helston, built to support more towns later.

- **Frontend:** Next.js + TypeScript, statically exported for IONOS web hosting.
- **Backend:** PHP JSON API on IONOS.
- **Database:** IONOS MySQL 8.
- **Scheduled imports:** GitHub Actions calls protected PHP ingestion endpoints.
- **First location:** Helston, with the database designed to support additional towns later.
