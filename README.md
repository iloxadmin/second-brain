# Adrian's Second Brain

Single source of truth for my context, shared by Claude and ChatGPT. Plain Markdown, stored in a private GitHub repo, edited in Obsidian.

AI assistants: read `AGENTS.md` first. It holds the rules and the routing table.

## Structure

| Folder | Holds | Changes |
|---|---|---|
| `00-inbox/` | Unsorted captures, AI-drafted notes awaiting review | Daily, emptied weekly |
| `10-me/` | Identity, values, how AI should work with me | Rarely |
| `20-areas/` | Ongoing responsibilities with no end date | Regularly |
| `30-projects/` | Finite efforts with a goal and an end | Often |
| `40-resources/` | Reference material and topics of interest | As needed |
| `50-archive/` | Finished projects and inactive areas | Append only |
| `_system/` | Conventions, templates, AI prompts | Rarely |
| `_attachments/` | Images and PDFs referenced by notes | As needed |
