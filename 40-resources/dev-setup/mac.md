# Mac development setup

What is installed on the Mac, so AI tools build with what is actually available.

## Runtimes (checked 2026-11-08)

- Python: system Python 3.9.6 only. Local tools that rely on Python should stay compatible with 3.9.
- Node.js and npm: installed under `/usr/local/bin`. On 2026-07-28 neither was present, which is why ThreatWatch is Python stdlib only.

## Work machines

- Installing runtimes or pip packages on work machines may need a change request.
